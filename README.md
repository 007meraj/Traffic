# Dhaka Jam Meter

A responsive, funny traffic opinion poll built with plain HTML, CSS and JavaScript.

## Run locally

Open `index.html` in a browser, or run `python3 -m http.server 8000` in this directory.
No installation, API keys or build step is required.

Votes are stored in each visitor's browser, not aggregated across visitors.

## Public hosting

In the GitHub repository's **Settings → Pages → Build and deployment**, choose
**GitHub Actions** as the source. Run the **Deploy GitHub Pages** workflow, or push
to `main`. Once deployment succeeds, the expected address is
https://007meraj.github.io/Traffic/ . GitHub Pages availability depends on the
repository visibility and account plan.
